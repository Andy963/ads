# 0035：服务商模型目录、服务选择与单份角色配置

状态：已接受，待部署。

## 决策

服务商拥有连接地址和加密凭据引用；模型仅在服务商目录中保存一次。模型配置 ID 是选择引用，不能以可能跨服务商重复的上游模型名称作为身份。

对话、转录、纠错分别维护启用模型引用和一个默认引用。非空启用列表必须有且只有一个默认模型；空列表不设默认。转录、纠错每次请求只使用各自默认模型，并在请求开始时固定两阶段配置。不存在自动并行、轮询或失败切换到其他候选模型的行为。对话和角色选择仅使用已启用的对话模型。

同步只向指定服务商的目录添加新模型，不覆盖已有别名、模型选项或推理强度，不自动启用新模型。默认推理强度为 `high`，默认选项为 `medium`、`high`，不使用服务端能力猜测隐藏该设置。

角色配置仅在角色表中保留每角色一条当前记录。迁移以旧角色编辑器实际显示的当前指令为准，删除旧版本表和指针表；旧运行时接口只作为读取、更新该唯一记录的兼容入口，不再保存历史。构建时的默认指令不是另一份用户配置。

## 迁移与边界

移动端模型管理使用分组列表、底部服务标签和系统对话框顶层的编辑页；启用开关即时持久化，失败回滚，默认模型独立单选。连接与阶段选项使用显式完成／取消流程，未保存更改需要确认丢弃。

抽屉、主界面、模型管理与角色指令共用系统字体及背景、强调色、分隔线、圆角变量，避免各页面分别维护主题。聊天正文、代码展示、状态语义和导航布局保持原有契约。

任务队列保留主分支已有的纵向滑动卡片栈，使用共享主题和紧凑按钮，不退回可滚动列表。排队消息与任务队列是独立组件，排队消息卡片不能因队列长度增加而被压缩。

失败消息的离线手动重试沿用原消息身份。重连队列快照、历史回放及身份对账均不得把尚未发送的手动重试当作旧失败记录清理；对账以兼容的可选字段标记同代失败是否可重试。运行中、已完成、已取消、过期身份和仅发送确认丢失的恢复记录继续遵守去重约束，不因失败可重试标记自动执行。

角色页沿用相同的分组列表和编辑页，模型与推理强度位于指令下方。选择模型或强度时仅更新对应字段，指令草稿独立保存；旧模型名仅用于显示匹配，不作为已持久化的配置 ID。重新选择同一显示模型也必须写入其配置 ID。模型不可用不应阻止用户保存指令，模型保存失败也不得丢弃指令草稿。

移动端采用紧凑密度：页面标题 22px，内容边距 8px／12px，分组间距 12px，角色切换条 36px 高。角色栏或非编辑区可横滑切换三个角色，边界不循环，切换不提交也不丢弃草稿。纵向滚动、文本编辑、屏幕边缘导航、多指和取消手势不得触发角色切换；保存中和选择弹层打开时禁用该手势。

对话顶部的模型与推理配置复用该编辑页。推理强度使用原生离散滑块，档位来自所选模型的配置，按强度排序；拖动仅预览，释放或键盘调整才提交，且不发送中间档位。单档模型显示固定档位，断线或运行锁定时禁止修改。

模型删除需要显式确认移除引用；服务默认和角色引用的调整与模型删除必须在同一事务内完成。没有剩余对话模型时清空角色模型引用，保留指令和其他角色字段。模型切换协议保留配置 ID 用于身份，另行提供显示名称供界面反馈。

旧对话模型的启用状态只迁移一次。尚未关联服务商的旧模型保留并显式显示为待关联，不推测用户希望使用的服务商。旧语音配置的连接迁入目录，复用原加密凭据引用；语音配置只保存阶段选项。

部署前需要验证角色冲突迁移、重复保存不增长记录、同名模型跨服务商隔离、每服务默认约束、同步不覆盖用户编辑、桌面和手机真实组件交互。代码修改不等于运行库已经迁移，也不等于已部署。

Native 运行时当前只实现 Chat completions。服务商显式指定其他协议时，在模型解析阶段拒绝，避免配置与真实请求端点不一致。HTTP 错误、流解析失败及收到结束标记后均释放上游响应体，防止重试积累未关闭连接。
