# 模型切换不写入聊天记录需求

## 背景

当前用户在 Web 对话中切换模型后，系统会在聊天记录中显示一条模型切换提示，例如模型已从某个模型切换到另一个模型。这条提示和实际对话内容无关。界面已有当前模型展示，因此这条聊天消息重复，并且会污染历史记录和重连回放。

## 目标

1. 模型切换仍然更新会话的有效模型。
2. 前端结果事件仍然携带当前有效模型，供界面状态同步使用。
3. 模型切换不再生成聊天中的可见 notice。
4. 模型切换不再写入 `HistoryStore`，重连后不应回放模型切换提示。
5. 模型 reasoning effort 仍按现有逻辑更新。

## 非目标

1. 不改变模型选择器 UI。
2. 不改变代理切换提示行为。
3. 不改变模型配置解析和 `setModelConfig` 行为。
4. 不迁移或清理已经存在的历史记录。

## 验收标准

1. 切换到不同模型时，`SessionManager` 的用户模型会更新。
2. 切换模型后的 prompt result 不包含模型切换 notice。
3. `HistoryStore` 只记录用户消息和 AI 回复，不记录模型切换 status。
4. 不影响相同模型重复提交时的无提示行为。
5. 相关单元测试覆盖模型切换不返回 notice 和 WebSocket prompt 历史不写入模型 notice。
